Recommended checks

Health:
GET http://localhost:5000/health
Auth:
POST http://localhost:5000/api/auth/register
POST http://localhost:5000/api/auth/login
Authenticated:
GET http://localhost:5000/api/users/me with Authorization: Bearer
GET/POST http://localhost:5000/api/profiles (Bearer token)
Content:
GET http://localhost:5000/api/movies
GET http://localhost:5000/api/series
GET http://localhost:5000/api/tv
My List:
GET/POST/DELETE http://localhost:5000/api/mylist (Bearer token)
Providers/ingestion:
POST http://localhost:5000/api/providers { code, name, m3uUrl?, xmltvUrl? }
POST http://localhost:5000/api/providers/:id/ingest/m3u
POST http://localhost:5000/api/providers/:id/ingest/xmltv
EPG:
GET http://localhost:5000/api/epg?channelId=&from=&to=
GET http://localhost:5000/api/epg/nownext?channelId=
Payments (stubs with live signature verification supported):
POST http://localhost:5000/api/payments/stripe/checkout
POST http://localhost:5000/api/payments/stripe/webhook
POST http://localhost:5000/api/payments/paystack/webhook
Note: Webhook routes expect raw body and signatures when secrets are set.
